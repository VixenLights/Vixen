# Documentation

Use these folders to decide where a document belongs:

- **[plans/](plans/)** — Implementation plans, requirements, and specifications for work to be done. Organize them by topic where a topic folder exists.
- **[reviews/](reviews/)** — Code reviews, design reviews, investigations, and other analysis of existing or proposed work.
- **[references/](references/)** — General reference material, such as guides, API notes, and durable background information.
- **[prompts/](prompts/)** — Reusable prompts and templates for AI-assisted tasks.

## Choosing a folder

Ask what the document is for: planning work belongs in `plans`; assessing or explaining work belongs in `reviews`; looking up stable information belongs in `references`; reusable instructions for an AI belong in `prompts`.
